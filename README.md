## Tiếng Việt

Trang web cá nhân của **Long Hoàng**, xây dựng bằng **Vite + React + TypeScript + Tailwind CSS + Framer Motion**.

### Trực tuyến

- **Cloudflare Pages:** https://longhoang.pages.dev/
- **GitHub Pages:** https://nguyenvanhoanglong478-source.github.io/personal-playground/

### Chạy trên máy & triển khai

Yêu cầu: **Node.js >= 18**.

```bash
npm install
npm run dev
npm run build
npm run pages:deploy
```

Mỗi lần push lên nhánh `main`, GitHub Actions trong `.github/workflows/deploy.yml` sẽ tự động build và cập nhật cả Cloudflare Pages lẫn GitHub Pages.

### Cấu trúc dữ liệu trong `src/data/`

- `src/data/profile.ts`: Thông tin cá nhân, liên hệ, mạng xã hội và nội dung song ngữ VI / EN.
- `src/data/experience.ts`: Các nhóm kinh nghiệm làm việc và công cụ áp dụng.
- `src/data/projects.ts`: 6 dự án tiêu biểu kèm liên kết GitHub tương ứng.
- `src/data/skills.ts`: Danh sách kỹ năng theo nhóm và đối chiếu dự án đã áp dụng.
- `src/data/siteStack.ts`: Danh sách các gói cốt lõi đọc trực tiếp từ `package.json`.

## English

Personal portfolio website of **Long Hoàng**, built with **Vite + React + TypeScript + Tailwind CSS + Framer Motion**.

Requires **Node.js >= 18**.

```bash
npm install
npm run dev
npm run build
npm run pages:deploy
```

Every push to `main` triggers the GitHub Actions workflow in `.github/workflows/deploy.yml` to build and deploy automatically to both Cloudflare Pages and GitHub Pages.

- `src/data/skills.ts`: Grouped skills cross-referenced with applied projects.
- `src/data/siteStack.ts`: Core packages read directly from `package.json`.
